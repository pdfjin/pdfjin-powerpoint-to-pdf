# 📄 pdfjin-powerpoint-to-pdf

> Convert PowerPoint presentations (PPTX) into PDF by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-powerpoint-to-pdf.svg)](https://pypi.org/project/pdfjin-powerpoint-to-pdf/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/powerpoint-to-pdf.html](https://pdfjin.com/pages/powerpoint-to-pdf.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-powerpoint-to-pdf
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-powerpoint-to-pdf.git
cd pdfjin-powerpoint-to-pdf
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-powerpoint-to-pdf --help
```

Use in Python:
```python
import pdfjin_powerpoint_to_pdf
```
